# Codex Context Picker VS Code Extension

This is the repository for the [Codex Context Picker](https://marketplace.visualstudio.com/items?itemName=ShadiAbuHilal.codex-context-picker) VS Code extension, which integrates with the [Codex](https://marketplace.visualstudio.com/items?itemName=openai.chatgpt) VS Code extension, allowing you to quickly add web page elements, files, folders, and code selections directly to your Codex prompt and context.

There are no source files in this repository because the extension is closed source.

You can make feature requests or report issues by filing an issue in this repository.

Extension documentation page: https://marketplace.visualstudio.com/items?itemName=ShadiAbuHilal.codex-context-picker
